# MISRA C:2012 Rule 15.4 engineering specification

Status: Implemented; independent validation pending

Original engineering text; licensed MISRA wording remains authoritative.

## Checker objective

Report an iteration statement that is terminated by more than one `break` or
`goto`.

## Analysis

The Clang adapter keeps a stack of breakable constructs (`for`, `while`, `do`,
`switch`). A `break` counts toward the innermost construct only when that
construct is a loop. Each `goto` records the loops enclosing it; each label
records the loops enclosing the label. After traversal, a `goto` counts toward
every loop that encloses the jump but not the label. A loop with more than one
terminating jump yields `misra-c2012-15.4-multiple-loop-exits` (Definite),
located at the loop keyword.

## Limitations

Independent oracle review and mutation testing are outstanding. Loops expanded
from macros are attributed to their use location. `return` statements are not
counted, which follows the rule's break/goto scope.
