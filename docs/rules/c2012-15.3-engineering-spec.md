# MISRA C:2012 Rule 15.3 engineering specification

Status: Implemented; independent validation pending

Original engineering text; licensed MISRA wording remains authoritative and is
not reproduced here.

## Checker objective

Report a resolved `goto` whose target label is not declared in the same block
as the jump or in a block that encloses the jump.

## Analysis

The Clang adapter tracks the stack of open `CompoundStmt`s during traversal.
Each `goto` records that stack. Each label is mapped to the compound statement
that directly contains it (looking through chained labels and `case`/`default`
labels). After traversal, a jump is compliant when its label's block is in the
jump's recorded stack. Containment is structural, not source-order based.

Diagnostic: `misra-c2012-15.3-label-not-in-enclosing-block`, Definite.

## Limitations

Independent oracle review, mutation testing, and Clang-version regression
pinning are outstanding. Jumps into a `switch` body from outside are covered by
the same block-containment test but have no dedicated fixture yet.
